Work in progress — this feature is still being developed, so results and the layout will keep changing. Pick an audio file (mp3, wav, m4a, ogg…) and Track Maker estimates its tempo and chord changes, entirely in your browser — the file is never uploaded. Treat the result as a first draft: it works best on songs with clear major/minor chords and is weaker on busy mixes, 7th chords and unusual voicings. Tidy it up in the Chord Sequencer afterwards.

YouTube Loop
Paste a YouTube link, mark a section (A–B), and loop it at any speed — slowing down or speeding up keeps the pitch the same — with an optional count-in before each pass. The last 5 videos and their settings are remembered on this device.
0:00.00 / 0:00.00
Press Loop at the start of the section (A), again at the end (B), and a third time to clear. Or type the times — minutes:seconds with decimals, e.g. 1:23.45 or 83.45.
Type any speed from 25% to 200% — for example 95 for 95% speed (0.95 works too). Pitch is kept as the speed changes; YouTube's player does the correction.
The count-in clicks at the song's tempo, slowed or sped up along with the video, then the video restarts at A. Tap along with the video to find the tempo (the current speed is taken into account).
Recent videos (saved on this device)
Video playback comes from YouTube's embedded player, loaded from youtube.com the first time you load a video. Loop points are checked about 30 times a second, so a loop can be a few hundredths of a second off.
Backing Tracks
Play a backing track from a local file, a network drive, or a link (YouTube, Spotify, or a direct link to an audio file). Everything you play goes into the history; drag tracks from there into a set list and play the whole list with a pause between tracks. It all stays saved in this browser, and a track keeps playing if you switch to another tab.
Files from a network drive work too — browse to them in the file window (a typed path like \\server\share can't be opened by a web page). Chosen files are copied into this browser's storage, so they keep playing offline and without permission prompts.
